# 06 控制功能安全设计

## 任务范围

本阶段只允许阅读资料、讨论和设计，不授权修改 PLC、ESP32、网页或发送控制命令。
本文件记录已确定的任务范围，不代表安全设计已经完成或控制功能已经实现。

- 只评估正常停止、产量清零和经过确认的参数修改。
- 永久排除远程启动，不直接写 Y 输出，不绕过 PLC 安全联锁。
- 正常停止不能代替现场急停。
- 分析身份权限、二次确认、上下限、操作日志、PLC 握手、超时和重复命令处理。
- MQTT 发布成功不能代表 PLC 已执行成功。
- 命令地址、写入能力和机械安全必须有证据，未知内容标记待确认。

## 按需阅读

1. [PLC 映射](../PLC-MAPPING.md) 和原始 PLC 材料。
2. 工作区 Upload0821 源码，仅阅读相关通信部分。
3. [架构](../ARCHITECTURE.md) 和必要的历史服务接口。
4. [需求](../REQUIREMENTS.md) 中控制与安全边界。

## 预期产出

输出有证据的控制信号清单、风险与权限表、命令协议、PLC 握手流程、异常处理、操作日志方案和现场测试清单。
区分已确认、推测、待现场确认和禁止实施。任何真实控制实施须另立任务并取得明确授权。
